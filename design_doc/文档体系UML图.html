    note for IterREADME "01-iterations/README · 拥有：MVP 迭代顺序表 01~09"

虚线箭头 ..> = 指针引用（箭头指向 owner）。例：DOCUMENTATION_STANDARD 的 §3.2 不再复制 7 份文档清单，而是指向 20-iteration-delivery。

时序图Agent 渐进式读取流程

一个任务从入口读到具体规则的四步，以及长任务中六个刷新点重新读取的时刻（见 90-simplicity-and-refresh）。

sequenceDiagram
    participant A as Agent
    participant AG as AGENTS.md
    participant IDX as INDEX.md
    participant RR as agent-rules/README
    participant Atom as 原子规则文件

    A->>AG: 1 读八耻八荣 + 披露入口
    AG-->>A: 指向 INDEX
    A->>IDX: 2 读事实源优先级 + 任务路由
    IDX-->>A: 路由到领域入口
    A->>RR: 3 读触发条件表
    RR-->>A: 命中任务类型
    A->>Atom: 4 按触发条件读对应规则
    Atom-->>A: 返回原子规则

    Note over A,Atom: 长任务刷新点：开工前 / 新增规则前 / 改接口或表前 / 跨前后端部署边界前 / 测试改策略前 / 最终回复前
触发条件示例：COS 与图片资产 → 70-object-storage；TripPlan / 推荐 → 60-agent-workflow-safety；数据库边界 → 50-domain-boundaries。
