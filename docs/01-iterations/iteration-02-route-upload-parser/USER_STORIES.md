## US-02.1 上传线路文件

作为登录用户，我希望上传 GPX / KML / GeoJSON 文件，以便系统生成可规划的线路资产。

## US-02.2 解析轨迹指标

作为用户，我希望系统解析轨迹的距离、爬升和轨迹 GeoJSON，以便后续线路展示和 Agent 推荐使用。

## US-02.3 补充线路语义标签

作为用户，我希望上传时补充线路标签，以便线路可筛选和推荐。
